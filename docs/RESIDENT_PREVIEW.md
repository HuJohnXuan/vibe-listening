# 房间、住客与本地音乐库

本轮交付：三种可切换的 Three.js 房间、程序化三维住客及互动，以及设备本地音乐库。它是可运行的动作与空间验证版本；概念图中的材质和精细程度仍是后续美术目标。

## 操作

- 点击沙发：走到沙发前，再坐下。
- 点击住客：挥手回应。
- 点击唱片柜下半部：前往挑唱片；唱机仍负责播放/暂停。
- 点击空地活动点附近：沿固定通道走过去。家具和不可达位置不会接收移动指令。
- 上方按钮提供相同操作，并补充去窗边、恢复自由活动、隐藏住客与近看住客。
- 滚轮缩放、拖动转视角；“复位”返回房间全景。
- 播放时住客轻微摇摆。用户安排后停留约 22 秒，再恢复自主活动；自主停留约 14–26 秒。
- 减少动态效果模式停用自主走动与循环动画，明确的地点指令直接到位。

短发、耳机、苔绿上衣、棕色长裤、仅有眼睛的面部沿用已确认方向。坐姿根据现有沙发的尺寸适配。城市天台使用蓝灰夹克、深色长裤和米色运动鞋；云端小屋使用米白上衣、灰蓝长裤和软便鞋。头部与耳机不随换装改变。

## 空间和本地音乐

- 空间选择：跟随歌曲标签或手动锁定三种房间；光线可选清晨、黄昏、深夜，天气可选晴、雨、雪。切换不重建播放器。
- 我的音乐：批量选择或拖入 MP3、M4A、AAC、WAV、FLAC、Ogg、Opus，单首上限 100 MB，实际播放格式支持由浏览器决定。读取内嵌歌名、歌手、专辑、时长、曲风和封面。无歌名用文件名，无封面用默认唱片图。
- 使用 SHA-256 判断同内容重复文件；逐首反馈，坏文件不阻断其他文件。IndexedDB 事务完成后才报告保存成功。资料可编辑，可移除应用副本，不改动原文件。
- 曲库仅保存在当前设备、浏览器和网站地址下。刷新后恢复；清理网站数据会丢失，原始文件应自行保留。没有云端上传或联网刮削。歌曲记忆仍只存在当前页面。
- 情绪与默认房间可以手动编辑；“估算节奏与响度”在设备内解码，支持 30 MB、10 分钟以内且时长已知的文件，计算最多前 90 秒的幅度与节拍。BPM 可能出现半速、倍速或无结果，dBFS 是文件幅度参考。它不识别曲风或情绪。
- 自动空间使用已有曲风／情绪标签的简单匹配，未知资料不会凭空生成相似歌曲推荐。轻快标签增加住客的轻晃幅度。
- 三维美术仍是程序化预览，不等同于已确认概念图的最终材质品质。

## 启动

在本目录对应的项目根目录运行 `npm ci`，再运行 `npm run dev -- --port 3012`。

Windows 下若使用映射或链接目录，Next.js 报错路径可能包含重复盘符。此时进入项目真实目录，再使用 Webpack 启动开发预览：

```powershell
node ./node_modules/next/dist/bin/next dev --webpack --hostname 127.0.0.1 --port 3012
```

打开 `http://localhost:3012`。本地预览不会更新 GitHub 或线上部署。

## 验证

`npm test` 执行生产构建和现有测试；新增路径与角色运动测试覆盖所有活动点连通、绕开茶几、途中改指令、减少动态效果和隐藏状态。`npm run lint` 检查代码规范。

浏览器检查应包含：坐下、起身前往窗边、途中改目标、挥手、隐藏/恢复、近看/复位、原有灯光与天气操作，以及拖动不误触。

本轮验证记录：生产构建、63 项测试、ESLint 均通过。浏览器使用自行合成音频验证了批量导入、重复跳过、损坏文件报错、编辑、120 BPM 估算、完整播放、切换空间不中断、刷新恢复和移除副本。三种空间与穿搭已实际检查，最终生产页面未发现控制台错误。测试曲库副本已清理。内嵌资料通过带 INFO 标签的 WAV 自动测试验证；未逐一实测所有编码格式或大曲库极限。
