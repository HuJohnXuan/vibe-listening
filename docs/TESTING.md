# 测试

## 自动化覆盖

`npm test` 先执行生产构建，再覆盖本地曲库、推荐、播放状态、Later、页面渲染、匿名设备 ID、
API 请求契约、远端状态恢复、播放上报、水合期间操作保留、快速写入串行化、历史与偏好恢复，
以及同步失败后的恢复、跨资源失败不被误清除和服务端规范时间戳回写。`npm run lint` 执行静态检查。

后端在 `backend/` 中运行 `python -m pytest tests -q`，覆盖模型边界、配置、设备隔离、恢复、
原子保存、去重、历史倒序与 500 条保留边界、偏好结构限制、用户容量、请求体上限、API 变更、
CORS 和安全错误响应。

原有前端测试继续覆盖：桌面播放器布局与设计令牌；10 首本地曲目的封面、试听、歌词和标签；
人工推荐优先与标签回退；3 首 Tonight's Picks；四路线 Radar；Later 的加入、去重、播放和移除；
收藏、播放/暂停、首尾切歌、进度格式与拖动；唯一当前歌曲状态；Listening Notes；响应式桌面尺寸；
以及范围外登录、搜索和科技辉光不出现。

## 运行方式

```bash
npm test
npm run lint
cd backend
python -m pytest tests -q
```

## 手工与部署验收

浏览器尺寸继续覆盖 `1440 × 900`、`1366 × 768` 和 `1024 × 768`，检查无水平溢出、主区
不重叠、控制区不遮挡，并连续操作播放、切歌、Radar 和 Later。部署验收还需验证 HTTPS 健康
检查、回环监听、systemd/Caddy 状态、严格 CORS、刷新恢复，以及 API 不可用时本地播放仍可操作。
