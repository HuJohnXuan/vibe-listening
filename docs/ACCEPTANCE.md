# MVP 最终验收记录

## 任务说明

- 首屏直接进入可操作播放器，没有 Landing Page、搜索、登录或账号入口；
- 本地播放、暂停、上下曲和进度控制可用，曲目结束后不强制自动播放下一首；
- 切歌后封面、歌曲信息、歌词、Listening Notes、Picks 与 Radar 使用同一状态源；
- Tonight’s Picks 固定三首且均有理由，Radar 完整展示四条路线；
- Picks 与 Radar 可加入 Later，Later 可播放和移除；
- 全部数据、封面和试听均为本地虚构内容，无后端、数据库或外部服务。

## 页面设计与设计语言

- 保持左右双区与底部控制区，不进行手机端重排；
- 使用暖棕木纹、黑胶、奶油色、金属和香槟金，玫红只用于进度与喜欢状态；
- 推荐、Radar 和 Later 使用连续列表或唱片内页面板，没有多层卡片；
- 没有青色、蓝色、紫色科技辉光、扫描圆环、粒子或雷达网格；
- 按钮具有默认、悬停、按下、选中和键盘聚焦反馈；
- 歌名与歌手过长时省略，推荐理由与歌词片段允许受控换行。

## 窗口与验证

- 浏览器重点检查 `1440 × 900`、`1366 × 768` 和 `1024 × 768`；
- 页面最小目标为 PC 浏览器，不包含手机端布局；
- 自动验证入口为 `npm test`，代码检查入口为 `npm run lint`；
- 测试覆盖曲库、推荐、播放状态、同步、Radar、Later、组件状态和最终响应式规则。
