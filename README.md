# Vibe Listening

### 给每首歌一个可以待下来的房间。

*A cozy, interactive 3D listening room — shaped by songs and your memories.*

拖动视角，点亮落地灯，让窗外下起雨。写下一句和这首歌有关的记忆，再把时间留给黑胶与炉火。

**Vibe Listening** 是一个运行在桌面浏览器里的沉浸式 R&B 播放器实验，用 Three.js 搭建真实的立体房间，让听歌多一点空间感和参与感。

![Vibe Listening：初版客厅与歌曲发现界面的实际运行截图](docs/images/listening-room.jpg)

上图为初版客厅截图；当前版本新增了住客、另外两种空间及本地曲库。

[快速开始](#快速开始) · [互动玩法](#房间里可以做什么) · [实现细节](docs/3D_ROOM.md) · [反馈想法](https://github.com/HuJohnXuan/vibe-listening/issues)

> 本分支支持三种互动房间、陪伴住客和设备本地曲库。内置 10 首虚构曲目，每首提供 6 秒合成试听；导入自己的音频后可完整播放。无需账号、API Key 或后端服务。

新增操作与限制见 [房间与本地音乐库说明](docs/RESIDENT_PREVIEW.md)。顶部“我的音乐”可批量导入、编辑资料和移除副本；房间上方可选择温暖客厅、城市天台、云端小屋及光线，住客随空间换装。

## 房间里可以做什么

| 你的动作 | 房间的回应 |
| --- | --- |
| 选择空间 | 切换温暖客厅、城市天台、云端小屋，住客随空间换装；也可恢复跟随歌曲标签 |
| 选择光线 | 清晨、黄昏、深夜，或恢复跟随歌曲 |
| 拖动房间，或使用视角按钮 | 从不同角度看沙发、唱片柜、窗户和壁炉 |
| 点击唱机 | 播放或暂停，唱片与唱臂跟随播放状态 |
| 点击落地灯 | 开关灯光，改变房间的明暗 |
| 点击客厅壁炉 | 开关炉火与暖光 |
| 点击窗户 | 在晴、雨、雪之间切换；“跟随歌曲”恢复自动氛围 |
| 切换“唱机特写” | 靠近黑胶，回到专注的唱机视图 |
| 点击住客、沙发、唱片柜或可达空地 | 挥手、坐下、前往唱片柜或沿固定通道走动 |
| 使用住客按钮 | 去窗边、自由活动、隐藏／显示、近看住客 |

房间操作也有可通过键盘访问的按钮。拖动视角不会顺带触发物件开关；WebGL 不可用时自动回退到唱机视图。

住客多数时间停留，偶尔随机前往活动点。用户指令优先，完成后停留约 22 秒再恢复自主活动。尊重系统“减少动态效果”偏好。角色保留短棕发、棕色耳机和仅有眼睛的面部；天台与云端分别使用蓝灰和米白穿搭。

## 导入自己的音乐

点击顶部 **“我的音乐 · 导入”**，选择或拖入多个文件。支持 MP3、M4A、AAC、WAV、FLAC、Ogg、Opus，单首最多 100 MB；实际解码播放能力取决于浏览器。

- 自动读取文件内嵌的歌名、歌手、专辑、时长、曲风和封面；无歌名使用文件名，无封面使用默认唱片图。
- 支持完整播放、进度调整、音量控制、编辑资料、手动选择情绪与默认房间。
- 按文件内容识别重复；逐首显示导入结果，损坏文件不阻断其他文件，存储不足时提示。
- 音频与资料保存在当前浏览器、当前网站地址的 IndexedDB 中，刷新后恢复。移除曲目只删除应用副本，设备原文件不受影响。

**不上传、不联网搜刮、不跨设备同步。** 清理网站数据会清空曲库，请保留原始音频。不同浏览器或网站地址的曲库互不相通。

编辑面板提供可选的“估算节奏与响度”：支持 30 MB 以内、时长已知且不超过 10 分钟的文件，计算最多前 90 秒。BPM 可能有半速／倍速误差，响度仅为文件幅度参考；结果可保存，目前不驱动房间或角色动作，也不自动识别曲风和情绪。

## 歌曲 × 记忆

同一首歌，可以属于不同的夜晚。

在歌曲的记忆输入框里试试 **“下雨的末班车”**，或 **“冬日炉边”**。歌曲标签决定基础氛围，记忆里的天气和时间关键词会进一步改变灯光与雨雪。

![Vibe Listening：输入“下雨的末班车”后的氛围预览](docs/images/rainy-memory.jpg)

这里使用本地关键词规则，不调用 AI 模型。记忆按歌曲分别保存在当前页面内存中，切歌后再切回来仍能看到；**刷新清空，不上传，也不写入浏览器存储**。

## 发现下一首

- **Tonight’s Picks**：最多三首推荐，附上推荐理由；本地歌曲缺少相似标签时显示空状态。
- **Radar**：沿四条发现路线探索曲目。
- **Later**：把感兴趣的歌放进稍后播放队列，再播放或移除。
- **Listening Notes**：用标签与短评描述听感；支持切歌、进度拖动、音量和喜欢反馈。

推荐采用人工关系优先、标签重合度回退的本地逻辑。

## 快速开始

安装 **Node.js 22.x**，然后运行：

```bash
git clone https://github.com/HuJohnXuan/vibe-listening.git
cd vibe-listening
git switch codex/listening-resident-preview
npm ci
npm run dev
```

打开终端显示的本地地址。无需配置环境变量。

生产构建与本地预览：

```bash
npm run build
npm run start
```

建议使用支持 WebGL 的现代桌面浏览器。当前针对 PC / 笔记本设计，尚未进行移动端重设计。

## 适合拿来做什么

体验一个有空间感的播放器，研究 Three.js 与 React 的互动连接，或以“歌曲 × 记忆”为起点探索自己的音乐产品。

当前已支持自己的本地音频，尚未接入外部音乐服务。演示曲目、歌手、专辑和歌词均为虚构内容；本页图片来自项目初版实际运行界面。公开在线演示地址尚未确认，可按上面的步骤本地体验。

## 当前边界

- 场景和角色是程序化三维预览，材质与衣物细节仍较简化。“挑唱片”通过走近、转向和停留表达，不包含实际拿取。
- 空间匹配使用曲风／情绪标签规则；轻快标签增加轻晃幅度，不做实时音频情绪识别或精确踩拍。
- 光线控制主要作用于房间灯光，天台远景天空尚未联动昼夜；部分中文情绪尚未映射到自动灯光规则。
- 点击窗户切换天气；指挥住客去窗边请使用“去窗边”按钮。
- 主要面向桌面窗口；窄侧栏布局、全部音频编码兼容性和大曲库性能仍需完善与验证。
